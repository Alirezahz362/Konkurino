
# 🎓 Konkurino

A modern web application rebuilt and developed with **React 19** and **Vite**.

## 🚀 Tech Stack

- **Core:** React 19, Vite 8
- **Styling:** Bootstrap 5, React-Bootstrap, SASS
- **UI & Animations:** GSAP 3, Swiper 14, React Icons, FontAwesome

## 📂 Project Structure


src/
├── assets/       # Custom fonts & media files
├── components/   # Reusable UI components
├── context/      # Global state management
├── hooks/        # Custom React hooks
├── layouts/      # Page layout components (Header, Footer)
├── page/         # Page components and views
├── services/     # API services & network requests
└── styles/       # SASS/CSS stylesheets


## 🛠 Getting Started

### Prerequisites

* Node.js (v18 or higher)
* npm or yarn

### Installation &amp; Execution


# Install dependencies
npm install

# Start development server
npm run dev



## 📜 Scripts

* `npm run dev` — Launch dev server with HMR
* `npm run build` — Build for production
* `npm run preview` — Preview production build
* `npm run lint` — Check code with ESLint
